# 🌐 Tilak Raj Rawat Portfolio

A modern developer portfolio built with **Next.js 15**, **React 19**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, **Lenis**, and **Resend**.

The portfolio showcases my background, technical skills, featured projects, experience, certifications, and provides a working contact form for recruiters and collaborators.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Tilakrajrawat/modern-portfolio.git
cd modern-portfolio
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Application will be available at:

```text
http://localhost:3000
```

---

## 🚀 Production Build

Create a production build:

```bash
npm run build
```

Run production server:

```bash
npm start
```
